# Kuboczoch Tutorial Skip

Stuck on a tutorial step that will not complete? Skip that step and continue the rest of the tutorial.

Adds a **Skip step** button below the current First Steps tutorial text. Each click marks one step as complete and saves your progress immediately. It does not complete the whole tutorial or give you the skipped step's items.

## Install

1. Download `KuboczochTutorialSkip-1.0.1.zip`.
2. Put it in `VintagestoryData/Mods` **without extracting it**.
3. Restart Vintage Story.

Client-side only. No server installation or configuration needed.

## Use

1. Start or resume the First Steps tutorial.
2. Hold **Alt** to release the cursor.
3. Click **Skip step** below the tutorial text.

**Skipped steps stay completed after removing the mod.** Restarting the tutorial resets all tutorial progress.

## Compatibility

- Vintage Story **1.22.7**.
- Translated button text for all 34 language files shipped with Vintage Story 1.22.7.

## Development builds

Extract that download once to get the installable mod ZIP; leave the mod ZIP itself intact.
